# S4 GAPS — what was missing vs "pro interface"

- No equity curve / equity history visualization (only static numbers).
- No prominent SIMULATED/PAPER mode label (mode shown as small text "Paper"/"LIVE").
- No kill-switch UI control or circuit-breaker readout beyond a hidden alert.
- Basic stat band (6 fixed cards) with uppercase labels and card-soup aesthetic — not high-trust.
- No responsive grid beyond two breakpoints; positions/trades tables cramped on mobile.
- No server time / last-updated indicator.
- No visual distinction between paper and live modes (color-coded pill).
